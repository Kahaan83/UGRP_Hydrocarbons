# Task 12 predeclaration: v5 set models (PairDeepSets, MolSets GNN, set transformer) retrained with curves and early stopping

Dev rows only (the v5 `--stage dev`: locked systems are never trained on or scored); the same rows, the same baseline-matched GroupKFold(5) folds, the same models, scaler, weights (system macro) and the same readings (R-WS4-1 gate, ternary, cold, UQ) as `scripts/v5/base/delta_ws4_mixture_ml.py`, which `scripts/v7/mixture/retrain_set_models.py` imports by path and runs with one function replaced (`fit_predict`).
Changes against the v5 dev reading (CPU, 60 epochs, no early stopping, `results/v5/BASE/delta_ws4_mixture_ml/<cand>/readings_dev.json`): up to 500 epochs on cuda; per fit a 20 % group-held-out validation split of the training systems (seeded by the fold, shared across properties for the set transformer) used for early stopping with patience 50 and best-state restore; curves logged per epoch (train and val loss). Model size, learning rate (2e-3), weight decay (1e-4), batch 512, 5 seeds, width 64 are unchanged: this is a training-length and stopping retrain, no hyperparameter search.
Comparator and reading rule: the LightGBM pair baselines read from BASE (identical to v5). Gate unchanged: a candidate passes only if the 90 % interval of the gain (pair MAE minus candidate MAE, system-macro, paired system bootstrap) is wholly above 0. A passing candidate becomes eligible for designation only, which is a user decision; nothing is exposed in `predict_fuel()`. The v5 numbers (viscosity: st passed on CPU 60 epochs; all density candidates failed) are the reference: v7 is read as "changed" only if the gate outcome or a mae_b moves beyond the v5 interval. One comparison per candidate and property, no multiplicity correction (stated). Training rows with a 20 % hold-out are fewer than in v5, so a worse MAE could come from the smaller training set; the curve reading states best-epoch location and the train/val gap.
Guard: `src/` and `results/v5/BASE/` hashed before and after the run and asserted unchanged.
