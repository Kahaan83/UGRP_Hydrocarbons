# Task 13 predeclaration: CPU tree models with reproduction gate, curves and nested Optuna

Models: viscosity_pair, density_pair, fusion_estimate, ysi_lgbm, freezing_step3, mixture_gbr (one section each below, committed before that model is run). Dev rows only; locked sets are never scored (the v5 and v6 scripts' own locked stages are not called).
Step 1, reproduction gate: refit with the original parameters on the same rows and folds as the script that produced the number in BASE or v6, and require the dev out-of-fold metric to match the number read from that file to 1e-6 relative. If it fails, the model stops and the reason is reported; step 2 is not run.
Step 2: the same model through `lgb.train` with curve logging under nested Optuna (`configs/v7/search_spaces.yaml: lgbm`: n_estimators 5000, early stopping 100; outer folds identical to the original, inner GroupKFold(3) on the training groups, MedianPruner warmup 20), 60 trials per outer fold, `timeout_s` 1800. Early stopping in the final fit uses a 15 % group-held-out split of the training rows. Objective: weighted validation L2 on the original training target.
Metric and comparison: the original script's dev out-of-fold metric, paired group bootstrap (4000 draws) 90 % CI of the gain (refit-original minus v7), groups as in the original. Gains are tuned on dev rows and are exploratory; nothing is adopted into `predict_fuel()` (a separate user decision).
Guard: the driver hashes `src/` and `results/v5/BASE/` before and after each run and asserts no change. Outputs per model: `repro_gate.json`, `summary.csv`, `curves.csv`, `curves.png`, `best_params.json`.
Reading rule: "v7 improves on the v5 model" only if the 90 % interval of the gain excludes 0 with positive gain; otherwise no evidence of improvement. One comparison per model, no multiplicity correction across models (stated, not hidden).

## viscosity_pair
Original: `scripts/v5/base/delta_ml_viscosity.py` functions (regenerate_rows, build_pairs, train_set, targets, fit_lgb) imported by path; the v4 leaderboard helper it loads from the removed `scripts/v3` is read from a git-recovered copy in `scratch/legacy` (no repo file changed). Rows: 15,827 refutas rows, dev systems (264), GroupKFold(5) on dev system_id. Gate number: `results/v5/BASE/delta_ml_viscosity/readings_dev.json` R-MLV-1 ml mae_b (macro per-system MAE of ln viscosity, warm dev rows). Training pairs: binary rows with x1 x2 >= 0.01, target clip(r, ±0.5)/(x1 x2), weight (x1 x2)^2 normalised per system; v7 prediction of a row is the sum over its pairs of x1 x2 g. Metric for the gain: per-system macro MAE on warm dev rows, systems as groups.
