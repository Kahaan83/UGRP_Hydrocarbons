# delta_api_route: declared readings (written before any result exists)

## Purpose

Check that the re-routed prediction API (decision D1 to D4 of the v5 API-route plan) reproduces the scoring route that BASE scored, instead of the old shipped API path. This README is committed before any delta result is generated. It declares what will be read and what counts as agreement; it reports no results.

## Baseline

`api_as_shipped` on the T2 flash set: bias -21.66 C, MAE 21.92 C, over 70 groups (`results/v5/BASE/cells_t2_flash.csv`, pooled row, `api_as_shipped`/`designated`). Values were verified against the CSV before writing (bias -21.656749, MAE 21.916079, n_groups 70, n_rows 70). `rows_t2_flash.csv` has 79 rows.

## Declared readings

- **R-API-1.** On all 79 T2 rows, the API's designated flash equals the route's `pred_lfl_overlay`, and `variants['v4_designated']` equals `pred_designated`, both to 1e-6 C (columns of `results/v5/BASE/rows_t2_flash.csv`).
- **R-API-2.** API kinematic viscosity and density equal the route's values on all T2 rows at the 9 BASE temperatures, to 1e-9 relative.
- **R-API-3.** Flash, heat and aromatics are bit-identical across T_K in {233.15, 288.15, 313.15}.
- **R-API-4.** Both D4 v5pool recipes re-predict through `predict()` within 0.01 C for flash, 1e-6 relative for viscosity, and exactly for heat. Density and freezing differences are reported with their cause.

## How to call it

Both entry points take a list of `(id, weight)` pairs, where `id` is an InChIKey or a SMILES string (any mix) and the weights are mass fractions. Pass `mole_fractions=[...]` (aligned with the list) to give mole fractions instead. Unparseable SMILES raise `ValueError`.

```python
from fuelblend.api.predict_blend import predict          # v4-compatible wrapper, now on the BASE route
from fuelblend.api.predict_route import predict_fuel     # route function itself

# a 60-component list, e.g. 60 registry hydrocarbons (equal mass weights)
comp = [(ik, 1.0 / 60) for ik in inchikeys_or_smiles_60]

r = predict(comp, T_K=288.15)                            # fuel_type="jet", composition_kind="known"|"reconstructed" optional
r["flash_point_C"]["value"], r["flash_point_C"]["method"]        # ideal_le_chatelier_anchored
r["viscosity_dyn_mPas"]["lo"], r["viscosity_dyn_mPas"]["hi"]     # NaN where the yaml has no margin
r["density_kg_m3"]["in_domain"], r["warnings"]

f = predict_fuel(comp, T_K=253.15)                       # same properties plus viscosity_kin_cSt, per-property status/coverage/variants
f["flash_point_C"]["variants"]
```

Read `in_domain`, `warnings` and `status` before using a value: a property with unmapped or substituted mass, or no yaml margin, has NaN `lo`/`hi` and `in_domain` False.

Inverse design on a user pool (names / SMILES / InChIKeys):

```powershell
.venv\Scripts\python.exe scripts/v5/run_design_userpool_v5.py --spec astm:jet_a,bis:jet_a1 --pool v5pool --n-starts 30 --seed 42 --out results/v5/BASE/delta_api_route/design_v5pool
# --pool v5pool | ext | comma-separated ids | a .txt file of ids;  --freezing-guard-K 4 for the indicative guard-band run (not certified)
```

It writes `designs.csv`, `constraints.csv`, `forward_check.csv` and `runtime.txt`. No design is certified; categories A / B and the blocking gaps are as in the design table above; `designs.csv` carries `category` (API-forward) and `category_design_side`.

## Whole-branch review

A whole-branch review (`.superpowers/sdd/2026-11-12-v5-api-route-and-design/final-review.md`) found one critical and six important issues. Fixed in this branch:

- **C1** (critical). Design freezing now uses the API function (ideal SvL, mole fraction, Coutinho tmap, RDKit MW); `design_forward_check` judges every constrained property (freezing, smoke, density, aromatics, heat, viscosity, flash) against the `predict_fuel` value with columns `design_pred`, `forward_pred`, `limit`, `design_meets`, `api_meets`; a design "meets limits" only if both meet every limit; a forward value of None gives `api_meets` False with the cause instead of an exception. The Task 7 designs were re-run and the table above rewritten (the old table overclaimed). R-API-4 in `delta.csv` is now computed by the script (it was `pending_task_6`); R-API-1 to R-API-3 are unchanged and pass.
- **I1.** A flash outside the nominal 0 to 100 C Antoine window keeps its value and the warning but gets NaN lo/hi, `in_domain` False and the domain reason `antoine_nominal_window_exceeded`. Mesitylene keeps its margin and warning (U1); the warning now also fires when mesitylene enters as a representative (M5).
- **I2.** The indicative interval is `None` unless the nearest T bin has at least 5 groups and lies within 10 K of T (flash has one pooled bin and needs 5 groups); it returns `T_bin_K`; it is not attached to the recalibrated-Refutas value. The K1 variant key is renamed `k1_cold_offset_in_sample`.
- **I4.** The grid SHA-256 is checked once per process; a mismatch adds the top-level warning `grid_sha_mismatch` (no exception). `RouteLibrary` now uses the read-only provider.
- **Minor.** `predict()` returns `viscosity_kin_cSt` (M2, so the K1 variant is reachable from the wrapper); stale docstrings in `predict_blend.py` and `docs/model_decision.md` line 91 corrected (M1, text only); the forward check is None-safe (M6); `delta.csv` R-API-4 filled (M3).

Left unfixed, with the reason:

- **I3.** `reproduce_base.py --full` would recompute the frozen `api_as_shipped` baseline with the re-routed API (`cells_t2_flash.py`, `cells_t2_bulk.py` import `predict` from `predict_blend`). Never run `--full`. The baseline is frozen and reproducible only at commit `5a62e20`; the default from-rows mode is unaffected.
- **I5.** The API reads `scripts/v5/base/cells_t2_flash.py`, `scripts/v5/s5_freezing_nalkane.py` and several `results/` CSVs at run time; a missing or regenerated file raises. Moving these into `src/` and a committed data file is a refactor outside this fix wave.
- **I6.** The net-heat CRC margin and `in_domain` True apply to any composition the caller labels `fuel_type="jet"`; `fuel_type` is trusted from the caller (stated in the `predict()` docstring).
- **M1 dead code** (`_resolve_components`, `_mix_residual_predict`, `_load_mix_models`, `_predict_flash` in `predict_blend.py`) is not removed (no callers, but outside this wave); `_predict_viscosity(use_residual=True)` still applies the GBM when called directly.

- The K1 variant at a temperature is built from a single group at some temperatures (no minimum n); not changed.
