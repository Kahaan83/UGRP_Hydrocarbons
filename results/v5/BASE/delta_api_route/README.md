# delta_api_route: declared readings (written before any result exists)

## Purpose

Check that the re-routed prediction API (decision D1 to D4 of the v5 API-route plan) reproduces the scoring route that BASE scored, instead of the old shipped API path. This README is committed before any delta result is generated. It declares what will be read and what counts as agreement; it reports no results.

## Baseline

`api_as_shipped` on the T2 flash set: bias -21.66 C, MAE 21.92 C, over 70 groups (`results/v5/BASE/cells_t2_flash.csv`, pooled row, `api_as_shipped`/`designated`). Values were verified against the CSV before writing (bias -21.656749, MAE 21.916079, n_groups 70, n_rows 70). `rows_t2_flash.csv` has 79 rows.

## Declared readings

- **R-API-1.** On all 79 T2 rows, the API's designated flash equals the route's `pred_lfl_overlay`, and `variants['v4_designated']` equals `pred_designated`, both to 1e-6 C (columns of `results/v5/BASE/rows_t2_flash.csv`).
- **R-API-2.** API kinematic viscosity and density equal the route's values on all T2 rows at the 9 BASE temperatures, to 1e-9 relative.
- **R-API-3.** Flash, heat and aromatics are bit-identical across T_K in {233.15, 288.15, 313.15}.
- **R-API-4.** Both D4 v5pool recipes re-predict through `predict()` within 0.01 C for flash, 1e-6 relative for viscosity, and exactly for heat. Density and freezing differences are reported with their cause.

## Grid SHA-256 and disclosure

`data/cache/pure_grid.npz` is an unpinned, gitignored binary built 2026-11-11. Its SHA-256 is pinned here and in `tests/test_delta_api_route.py`:

## Out of scope

Grid rebuild; U1 promotions (K1, F1, LFL overlay); distillation.

## Result

Generated by `scripts/v5/base/delta_api_route.py` (run on branch v5; grid SHA-256 pinned by `tests/test_delta_api_route.py::test_grid_pinned`). Fuel loop as in `cells_t2_flash.main` (`kind_bins`, then `map_bins`); `predict_fuel(..., fuel_type="jet")` is called on `[(reg.ik[i], w)]`. 81 fuels (the 79 flash rows plus 2 fuels with viscosity or density targets only). Files: `delta.csv`, `api_vs_route_rows.csv`, `forward_demo_60.csv`.

| Reading | Rows | Max difference | Tolerance | Pass |
|---|---|---|---|---|
| R-API-1 | 79 | 4.98e-07 C | 1e-6 C | yes |

Notes on how each reading was evaluated:

- R-API-1: the 4.98e-07 C maximum is storage rounding. The route columns of `rows_t2_flash.csv` were written with `%.8g`; the API value is full precision. Both the designated (overlay) comparison and the `v4_designated` comparison are inside 1e-6 C on every row.
- R-API-2: the route values were computed directly with `composition_route.refutas_nu_safe` on the mapped fuel (full precision) at the nine BASE nominal temperatures (233.15, 253.15, 273.15, 288.15, 293.15, 313.15, 333.15, 353.15, 373.15 K). As a secondary check against the stored `rows_t2_bulk.csv` designated predictions (8 significant digits), the maximum relative difference is 4.5e-08 for viscosity and 6.8e-09 for density, which is the CSV rounding level and is not the reading.
- R-API-3: flash, net heat, aromatics wt % and aromatics vol % are bit-identical across 233.15, 288.15 and 313.15 K for every fuel.

60-component demo (`forward_demo_60.csv`): the Task 2 blend (registry hydrocarbons C8-C16 with grid or flash data, seed 0, equal mass weights) at 233.15, 253.15, 288.15 and 313.15 K, every property with method, status and coverage. It runs without exception; viscosity and density rest on 55 % substituted mass and 5 % dropped mass and are not in domain.
