# v4 Task 10: conformal uncertainty margins computed from residuals

Generated by `scripts/v4/build_uncertainty_v4.py` (do not edit by hand); every number below is read back from `configs/uncertainty_v4.yaml` or recomputed from the cited residual files. Library: `src/fuelblend/uq/conformal.py`; tests: `tests/test_v4_conformal.py`.

## Method
- Residual = predicted - measured. The independent unit is the **group** (fuel for CRC/real fuels, system for lab and SLE data, blendstock CAS for octane, inferred T-code for AJFTD smoke point); a group's score is its maximum unsafe-side residual, so duplicate rows never inflate n.
- Margin = the k-th smallest of n group scores, k = ceil((n+1)(1-alpha)), alpha = 0.1 (ruling R3: `inf` iff k > n, i.e. fewer than 9 groups at alpha 0.1; exactly 9 groups gives the maximum). `inf` is written as the string `inf` with a `reason`; no typed substitute is ever supplied.
- Margins are set from **dev** (out-of-fold) residuals only. The **locked** coverage table below is a counts-only check; it was not used to choose or adjust anything.
- One-sided margins can be negative (the model never over-predicted); `applied_margin` floors them at 0. Two-sided margins (density in kg/m3; viscosity in ln-ratio) take the per-group max |residual|.
- Where Tasks 14/15 had not saved per-row residuals (octane, smoke point) this script re-runs their deterministic CV loops and saves the rows to `results/v4/U/octane_oof_residuals.csv` and `results/v4/U/smoke_point_oof_residuals.csv`.

## Caveats common to all entries

- CRC647 compositions are reconstructed (ruling R10), so every CRC-based margin includes reconstruction error and is conditional on that reconstruction.
- Conformal validity assumes the new group is exchangeable with the calibration groups. A new fuel family (diesel, gasoline, bio-blend) or a new test temperature breaks that assumption; the margins say nothing about them.
- v3 margins in `configs/uncertainty_v3.yaml` are untouched; consumers (Task 17) must read `configs/uncertainty_v4.yaml`.
