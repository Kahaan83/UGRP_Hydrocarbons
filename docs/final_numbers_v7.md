## C. Limits

* Real-fuel freezing point: status: no skill shown. Cold viscosity: status: no skill shown.
* Pure-compound predictions carry no conformal margin; the MAE is a dev-row CV estimate, not a certified bound.
* Un-refit Antoine constants are not evaluated for C10+ alkanes (trap 3); Antoine constants predicted by parameter heads are not used for flash.
* The fresh external-lock flash set (HANNA vs UNIFAC) remains unspent.
* No laboratory validation exists; certification is model-level only.
