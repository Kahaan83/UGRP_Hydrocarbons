## 2. Answers to Acceptance Criteria

### (1) CRC measurements/near-duplicates in training?
**Verdict: PASS (0 measurements, 0 near-duplicates).**
- **Direct CRC measurements:** Exactly 0 rows in `model_table.csv` S1. CRC 647 real fuels have `kind = 'real_fuel'` and system IDs formatted as `fuel:<id>`. Rule R1 in `src/fuelblend/data/model_table.py` strictly mandates `composition_level in {'L2', 'L3'}`, completely excluding bulk real fuels from training tables. CRC data is evaluated exclusively via bulk-route reconstructed pseudo-compositions in offline hindcast inference (`results/hindcast/hindcast_predictions.csv`).
- **Near-duplicates in training:** Exactly 0 rows under the acceptance criterion (`CRC system component sets overlapping >=80% with training blends, same property, T within 2 K, value within 5%`). Because CRC fuels have no speciated component lists (`comp_inchikeys == '[]'`), component overlap is 0%. Even comparing against 36-component bulk reconstructions, training blends in S1 are binaries and ternaries, yielding maximum Jaccard overlap $\le 8.33\% \ll 80\%$.
- **Relaxed property-only coincidence analysis:** Searching without the component overlap constraint yields 67,324 pairings across 147 unique training systems (67,323 density, 1 kinematic viscosity; 0 flash point or distillation). These pairings arise because bulk jet fuel density (775–840 kg/m³) naturally overlaps with pure and binary liquid hydrocarbons at similar temperatures. This is physical fluid property overlap, not data copying or leakage.

### (2) Antoine shared-compound vs true leakage verdict with row IDs if fail
**Verdict: PASS on true leakage; PASS (low severity / benign) on shared-compound data-flow; FAIL on parameter provenance (C3c).**
- **True mixture leakage:** Exactly 0 rows. `refit_antoine.py` strictly enforces `(m.property == 'vapor_pressure_kPa') & (m.n_comp == 1)`. Although 12 mixture VP rows in `measurements.csv` share a `system_id` with flash LOSO systems (e.g., binary VLE data), they are structurally excluded by `n_comp == 1`. Mixture flash rows are never read by Antoine refit.
- **Shared-compound leakage:** 13 of the 32 compounds in the 31 flash LOSO systems use Antoine constants from `refit_measured` (12 refitted from pure ThermoML vapor pressures; 1 anchored from WebBook). Severity is classified as **LOW / BENIGN** and does **NOT** invalidate the LOSO claim. Antoine parameters are single-component thermodynamic scalars ($P_i^{\mathrm{sat}}$) necessary to evaluate Raoult's law $\sum (x_i P_i^{\mathrm{sat}} / LFL_i) = 1$. They contain no blend composition, interaction, or mixture flash point data. Holding out pure-component saturation vapor pressures would render the physics baseline unsolvable.
- **Antoine provenance audit (C3c): FAIL on 8 unverified compounds.** 8 of the 19 compounds added on Nov 3 have no Antoine tables on NIST WebBook despite the `antoine_source='webbook'` label (hexylbenzene, isocetane, octylbenzene, dodecylbenzene, 2,3,3-trimethylpentane, trans-1,4-dimethylcyclohexane, cis-1,4-dimethylcyclohexane, cis-1,2-dimethylcyclohexane).
