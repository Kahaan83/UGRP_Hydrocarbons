## 1. Summary of Work

Task T1.3 standardizes all compound identifiers across the repository into a single canonical compound registry (`data/compounds_canonical.csv`). Each compound is identified by its standard 27-character InChIKey, canonical isomeric SMILES, and standard InChI generated via RDKit (`2026.03.6`).

Curated metadata (CAS Registry Number, common/systematic name, molecular formula, molecular weight, carbon count, hydrocarbon status, and fuel class) are standardized. In addition, all physics parameters (Antoine coefficients and Low Flammability Limit values) from `data/unified/compounds.csv` are preserved so downstream physics baselines and mixture models remain fully operational.

Original files `data/unified/compounds.csv` and `compounds.csv` were preserved without modification.

Curated name `tetralin` and CAS `119-64-2` were merged into the canonical registry.

## 5. Verification & Test Status

Automated test suite `tests/test_compounds_canonical.py` covers 8 test cases:
1. `test_schema_and_columns`: Verifies all 21 standard columns are present.
2. `test_valid_inchikeys`: Verifies every row has a valid 27-character InChIKey (`^[A-Z]{14}-[A-Z]{10}-[A-Z]$`).
3. `test_unique_inchikeys`: Verifies 0 duplicate InChIKeys in canonical output.
4. `test_all_unified_compounds_mapped`: Verifies 100% of compounds from `data/unified/compounds.csv` are present.
5. `test_all_root_compounds_mapped`: Verifies 100% of compounds from `compounds.csv` (root) are present.
6. `test_valid_rdkit_smiles`: Verifies all SMILES parse into valid RDKit molecules and round-trip to the exact same InChIKey.
7. `test_valid_classes`: Verifies all class labels are in the valid set and match `is_hydrocarbon`.
8. `test_preserved_physics_parameters`: Verifies Antoine constants and LFL values from unified compounds are preserved without loss.
