# v5 WS5 plan: GH-GNN non-ideality in Le Chatelier flash (test)

Roadmap item: WS5 of `docs/superpowers/plans/2026-11-13-v5-certification-and-ml-roadmap.md`. Delta folder: `results/v5/BASE/delta_ws5_ghgnn/` (its README holds the declared readings and gate; this plan holds the work steps). Branch: worktree off v5 (base 50f4333 as launched).

Goal: decide, on pre-declared gates, whether replacing gamma = 1 by a GH-GNN-derived Wilson gamma lowers flash-point error on lab mixtures (31 systems), CRC 647 r3 and T2 measured fuels without raising over-prediction. Live flash code is not changed.

## Steps

1. **Acquire and read the code.** `git clone` `edgarsmdn/GH-GNN` to `data/raw/ghgnn_code/repo`; read `notebooks/GHGNN/ghgnn.py`, `GHGNN_architecture.py`, `mol2graph.py`; inspect the four pickles with `pickletools` before loading (only `rdkit ExplicitBitVect` globals). Dependencies installed with `pip --target data/raw/ghgnn_code/site` (torch_geometric 2.8.1, mordredcommunity 2.0.7, tqdm, psutil, xxhash); `torch_scatter` replaced by a small pure-torch stand-in (no wheel). Record in `SOURCES.md`.
2. **Reproduce the repo.** `scripts/v5/ws5/validate_ghgnn.py`: 400 hydrocarbon rows of the repo's stored predictions; accept max |diff| < 1e-3.
3. **README with declared readings and gate, then commit** (before any flash score).
4. **Wrapper tests (failing first)** in `tests/test_ws5_ghgnn.py`: (a) ln gamma_inf = A + B/T from two temperatures reproduces a third to 1e-4; (b) Wilson inversion round-trips on random (a, b) and reports failures; (c) Wilson gamma at x -> 0 recovers ln gamma_inf; (d) gamma = 1 wrapper equals `flash_point_unifac_detail(use_unifac=False)` for lab rows to 1e-9; (e) AD table stores real Tanimoto and class counts for interpolation pairs.
5. **Implement** `scripts/v5/ws5/ws5_flash.py` (sets, pair cache, Wilson, solver wrapper, bootstrap, margins, AD table, R-1 to R-5) and the pair cache `results/v5/BASE/delta_ws5_ghgnn/pair_cache.csv`.
6. **Baseline reproduction check** (gamma = 1 equals stored values) before any GH-GNN score.
7. **Run** in the background; append results to the README; update `docs/claims_register.md` (provisional CLM number, parallel branches also use CLM-50 and up) and `docs/model_decision.md`.
8. **Verification:** targeted tests, then one full pytest at the end (baseline: 1 failed `tests/test_v4_sle.py::test_default_mode_unchanged`).
9. **Commit** on the worktree branch, no attribution lines, no push.
