# v5 WS6: real fuels from GCxGC class x carbon-number distributions

> Roadmap parent: `docs/superpowers/plans/2026-11-13-v5-certification-and-ml-roadmap.md` (WS6; that file is in the main checkout, not in this worktree).
> Executed on branch `worktree-agent-ab5aceb174f266a9b` (worktree HEAD 6204538). Delta pattern: README with declared readings first, results appended later.

**Goal.** Test whether a model that sees the measured class x carbon-number matrix of a real fuel (GCxGC) can beat (a) the current physics on mapped representatives,
(b) physics plus a constant offset, and (c) a constant, on density, flash, kinematic viscosity at -20 and -40 C, freezing and smoke, with direction-aware safety metrics.
Targets named by the roadmap: the cold-viscosity margin (`configs/uncertainty_v4.yaml` raw Refutas margin is `inf` below 283 K, so every T2 scoreboard cell at 233.15 K shows `inf`)
and freezing on real fuels.

**Out of scope / not touched.** `configs/*.yaml` margins, `predict_fuel`, `engine_v4.py`, `library_route.py`, `verification:` flags. Margins from this delta are proposals marked "needs user decision".
